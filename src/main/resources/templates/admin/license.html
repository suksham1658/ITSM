Install / renew license

Upload the .lic file sent by your software vendor. It is checked before it is saved, so an invalid file never replaces a working one. Applies immediately — no restart.

The file can also be placed directly in the config folder (set by ITSM_CONFIG_DIR, by default D:\itsm-config\itsm-license.lic) and will be picked up within a few minutes or at the next restart.
