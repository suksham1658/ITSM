Reporting line (Service Request approvals)

Service Requests go to the manager first. If an HOD is set here, the approvals end at that HOD: up the chain to the HOD when the HOD is above this person, otherwise straight from the manager to the HOD. With no HOD set, they go up the chain until someone with the HOD role. The manager is filled from Active Directory at each login; set it here if the directory has none. Changes apply to new requests, not to requests already raised.
